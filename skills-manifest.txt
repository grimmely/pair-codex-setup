# Portable skills

handoff
  Installed from the public Pair Codex Handoffs tool. Guides confirmed private
  session send/receive flows through user-configured Git storage.

grilling
  Required by AGENTS.md when the user proposes an implementation. One material
  challenge only, then return to the feedback loop.

to-tickets
  Carries the investigate -> show fact / test -> show red / minimal code
  -> show green slicing rule.

unslop
  Keeps pairing responses concise without removing useful reasoning.

zed-pr-review
  Opens a GitHub PR in an isolated Zed checkout with its actual comparison base
  and changed-file Outline Panel. Supports automatic skill selection.
